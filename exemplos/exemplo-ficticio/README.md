# Projeto de exemplo fictício

Especificações inventadas, no mesmo formato usado com o Pirilampo, para os testes e a
demonstração do Prumo. Nenhum dado, texto ou imagem de projeto real: CPFs e CNPJs são
gerados, nomes terminam em "Exemplo" e e-mails usam o domínio `exemplo.com.br`.

```bash
npm run prumo -- verificar --specs exemplos/exemplo-ficticio
npm run prumo -- capturar  --specs exemplos/exemplo-ficticio
```
